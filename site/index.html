Install

  1. Download and unzipGet ligatures.zip and double-click it.
  2. Move to ApplicationsDrag Ligatures into your Applications folder. Upgrading keeps your installed fonts and favorites.
  3. Approve it onceThe app isn't notarized by Apple. On first launch, click Done, then open System Settings → Privacy & Security and click Open Anyway.

FAQ

Is Ligatures really free?

Yes. Ligatures is free and open source under the MIT License, and every font it offers is free to download. There's no account, subscription or tracking.

Which fonts can I install?

Every family on Google Fonts and the free families on Fontshare, about 2,000 in total. Families both libraries offer appear once, from Google Fonts.

Can I use the fonts commercially?

Google Fonts families are open source, mostly under the SIL Open Font License. Fontshare families use the SIL Open Font License or the ITF Free Font License, which allows personal and commercial use. Each family's license is shown in its details panel.

Where are fonts installed, and how do I remove them?

In your user Fonts folder (~/Library/Fonts), so every app can use them right away. Uninstall from the font's details panel; the files go to the Trash. Ligatures only ever removes fonts it installed.

Why does macOS warn me the first time I open it?

Ligatures isn't signed with a paid Apple Developer ID, so macOS can't verify it automatically. Approve it once in System Settings → Privacy & Security → Open Anyway. The source code is public on GitHub if you'd like to check or build it yourself.

Which Macs does it run on?

Any Mac with macOS 12 Monterey or later, on Apple silicon or Intel. Nothing else needs to be installed.
